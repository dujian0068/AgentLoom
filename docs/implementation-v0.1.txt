外部 MCP HTTP/SSE 发现与调用；托管 Python 目录/Git、容器构建与 stdio 服务代码。

已验证
Vue 类型检查与生产构建通过。
23 项集成测试通过；涵盖发布限制/快照、空间/API 鉴权、密钥不回显、Skill 上传/路径、关键词及混合检索、子 Agent 契约与继承模型、Plan 与文件产物、取消、缺少 Docker 时拒绝宿主执行。
真实 MCP Streamable HTTP 本地服务发现与调用成功。
Vue 浏览器验证：登录、Agent 创建/保存/编辑、子 Agent 创建/编辑、发布后弹窗关闭、版本选择入口、发起运行、事件流与输出。
页面验证使用 work/qa 内独立测试账号与替身模型；正式 data 内没有测试账号或模型 Key。

尚未验证或当前限制
没有用户真实模型 Key，供应商端到端响应与工具调用尚未实测；模型/embedding 逻辑测试使用替身。
本机没有 Docker，托管构建与 Skill 脚本容器执行代码尚未实机验证。Compose 模板未实机构建。
Git 导入未完成远端集成验证；首版仅公开 HTTPS Git。
不承诺完整兼容所有 Codex/Claude Code Skill 宿主工具或自定义依赖。
当前没有后台索引队列、索引重建、私有 Git 凭据、分布式执行、子任务并行/递归。
SQLite 向量相似度用于小规模测试。未配置 embedding 时明确使用关键词检索。
文件索引失败可重新上传；新上传文档需要重新发布 Agent 后纳入快照。删除文档使历史检索也不可再访问。

使用顺序
由用户首次创建管理员账号。
模型连接页添加实际 Base URL、模型 ID、Key，并测试连接。
添加所需 Skill/MCP/知识库，配置 Agent，发布后调试。
通过空间成员页创建 API Key 后按发布页面示例调用。
详见项目 README.md。
