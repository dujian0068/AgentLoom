## 怎样使用这个文档站

- **左侧目录**切换文档，正文内链接直接进入对应页面；手机点击“文档目录”。
- **右侧本页目录**定位章节；手机点击页首的“本页目录”。
- 点击顶部**搜索文档**，或按 `⌘ K` / `Ctrl K`，搜索“上下文”“共享存储”“HookManager”等关键词。
- 页面底部的**上一篇 / 下一篇**用于连续阅读；浏览器返回也可以回到上一页。
- SVG 架构图直接显示，点击可以打开原图；Mermaid 关系图也会显示为图形。
- 源码链接另开 GitHub；正文仍来自仓库中的 Markdown，修改后重新构建即可更新网页。
